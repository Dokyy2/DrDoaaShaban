# عيادة د. دعاء شعبان — نظام الحجز والإدارة

نسخة تجارية تجريبية تجمع موقع الحجز ولوحة الإدارة. **Google Sheet هو المصدر الأساسي**، وSupabase نسخة تشغيلية متزامنة للوحة.

## التشغيل والوصول

- موقع الحجز: [https://dokyy2.github.io/DrDoaaShaban/](https://dokyy2.github.io/DrDoaaShaban/)
- لوحة الإدارة: [https://dokyy2.github.io/DrDoaaShaban/dashboard/](https://dokyy2.github.io/DrDoaaShaban/dashboard/)
- GitHub Pages منشور من فرع `with-admin` ومجلده الجذر.
- الدخول بحساب Supabase مفعّل، ويجب أن يكون دوره `secretary` أو `doctor`. رابط اللوحة غير ظاهر في قوائم موقع الحجز، لكن الحماية الفعلية بتسجيل الدخول وصلاحيات قاعدة البيانات والجسر.

## تدفق البيانات

1. المريضة ترسل الحجز من الموقع إلى Apps Script.
2. Apps Script يحفظه في الشيت أولًا ثم يزامنه إلى Supabase.
3. لوحة الإدارة تقرأ من Supabase، وترسل التعديلات إلى Apps Script؛ يحفظها الجسر في الشيت ثم يحدّث النسخة المتزامنة.
4. إعادة المحاولة تعالج الأحداث التي لم تكتمل مزامنتها.

المعاينة على `localhost` تحاكي الحجز ولا تحفظه. لا تستخدم الشيت الأصلي لبيانات اختبار.

## الحالة الحالية — 2026-11-08

- Apps Script Web App الإصدار 2 جاهز، وفحصه يعيد `configured: true` مع مشغّل إعادة المحاولة.
- هجرة `20261108001453_sheet_canonical_lockdown` مطبقة؛ لا تعيدي تشغيل ملفات SQL على قاعدة البيانات الحالية.
- صلاحيات Supabase تفصل الدكتورة عن السكرتارية، والمرفقات وملاحظات الدكتورة محمية. التغييرات الكتابية تمر عبر Apps Script.
- الشيت الأصلي أصبح **مقيّدًا**: لا وصول عام بالرابط؛ المالك والدكتورة فقط لهما وصول مباشر. فريق العيادة يستخدم لوحة الإدارة.
- المفتاح السري لا يوجد في المستودع؛ يبقى في Script Properties. مفاتيح Supabase القديمة عُطلت، ومفتاح JWT السابق أُبطل.
- اختبارات الجسر الاصطناعية: 15/15 ناجحة. تم التحقق من حجز ومزامنة اصطناعيين على شيت مرحلي ثم حذف بيانات الاختبار.
- قبل تشغيل الإجراءات القديمة على كل السجلات: شغّلي معاينة المطابقة التاريخية بحساب الدكتورة وراجعي المطابقات الملتبسة؛ السجلات غير المرتبطة لا يتم تعديلها تلقائيًا.

## الملفات المهمة

- `dashboard/`: لوحة الإدارة الكاملة.
- `js/config.js`: مفتاح Supabase العام ورابط Apps Script العام المخصص لاستقبال الحجز؛ لا تضعي فيه مفتاحًا سريًا.
- `google-apps-script/commercial/Code.gs`: مصدر جسر Apps Script المستقل.
- `google-apps-script/commercial/README.md`: إعداد الجسر والحالة التشغيلية.
- `supabase/07_sheet_canonical_lockdown.sql`: الهجرة المطبقة على قاعدة البيانات الحالية؛ مرجع فقط، لا تعيدي تنفيذها.
- `tests/bridge-guards.test.cjs`: اختبارات الحماية الاصطناعية.

## فحوصات محلية

من مجلد المشروع شغّلي:

```powershell
node --test tests/bridge-guards.test.cjs
```

لا ترفعي بيانات مرضى أو نسخ Excel أو مرفقات أو مفاتيح سرية إلى GitHub.
