# عيادة د. دعاء شعبان — نسخة الإدارة المحلية

هذه نسخة تجريبية منفصلة للحجز ولوحة الإدارة. **قاعدة Supabase هي المصدر الأساسي** في هذه النسخة. شيت Google الأصلي يظل خاصًا بإصدار الحجز من غير لوحة الإدارة، ولا تتصل به هذه النسخة.

## التشغيل والوصول

- افتح المشروع من خادم محلي، لا بفتح `index.html` مباشرةً.
- الموقع المحلي: `http://127.0.0.1:5501/`
- لوحة الإدارة: `http://127.0.0.1:5501/dashboard/`
- الدخول بحساب Supabase مفعّل ودور `secretary` أو `doctor`.
- قاعدة التجربة تحتوي السجل السابق للمراجعة؛ لم تُحذف الحجوزات أو ملفات المريضات.

## تدفق البيانات

1. حجز المريضة يرسل إلى Supabase Edge Function `clinic-db-booking`.
2. الدالة تستدعي `public.create_booking` وتُسجل بيانات الحجز والأحداث داخل قاعدة Supabase. رقم الطلب ثابت وتُعاد نتيجة الحجز نفسه عند تكرار الطلب، كما تُسلسل الدالة فحوصات التكرار والسعة اليومية.
3. لوحة الإدارة تقرأ الحجوزات والإعدادات من Supabase، وتحفظ تحديثات الحالات والدفع والملاحظات هناك مباشرةً مع سياسات RLS حسب دور المستخدم.
4. لا تُكتب أي بيانات من نسخة الإدارة المحلية إلى Google Sheet.
5. فتح `index.html` كملف `file://` فقط يشغّل معاينة غير متصلة ولا يحفظ حجوزات.

## الحالة — 2026-11-08

- `clinic-db-booking` نشطة على Supabase (الإصدار 2)، ومفتاح الخدمة محفوظ في بيئة الدالة ولا يظهر في ملفات الواجهة.
- هجرات `supabase/08_supabase_canonical_admin.sql` و`09_role_financial_separation.sql` و`10_booking_idempotency_and_atomic_limits.sql` مطبقة على قاعدة التجربة. صلاحية الحجز العامة محصورة في الدالة الخادمية.
- إدارة الحالات والمواعيد والحسابات أصبحت على Supabase. السكرتارية لا تقرأ حقول الدفع أو الأسعار أو الملاحظات المالية؛ العمليات المالية من صلاحية الدكتورة فقط.
- السجلات السابقة محفوظة في قاعدة تجربة Supabase، ويبدأ مسار المتابعة من الحجوزات الحالية والمستقبلية.
- نسخة الإدارة متاحة للاختبار على فرع `with-admin` في GitHub Pages. إصدار الحجز بدون إدارة وملف Google Sheet الخاص به منفصلان ولم يتغيرا.
- تعذّر من بيئة التنفيذ الحالية إجراء طلب HTTP مباشر إلى Edge Function بسبب منع الاتصال الخارجي؛ يلزم تجربة حجز اصطناعي من الموقع المحلي ثم التأكد من ظهوره في اللوحة قبل النشر النهائي.

## الملفات المهمة

- `dashboard/`: واجهة الإدارة، قراءة وكتابة مباشرة إلى Supabase.
- `js/config.js`: عنوان Supabase ومفتاح النشر العام فقط.
- `js/bridge-client.js`: اتصال الحجز بالدالة `clinic-db-booking`.
- `supabase/functions/clinic-db-booking/index.ts`: دالة الحجز الخادمية.
- `supabase/08_supabase_canonical_admin.sql`: مرجع الهجرة المطبقة؛ لا تعيدي تشغيلها يدويًا.
- `supabase/09_role_financial_separation.sql`: حدود قراءة البيانات المالية والملاحظات.
- `supabase/10_booking_idempotency_and_atomic_limits.sql`: رقم الحجز الثابت ومنع التكرار وتجاوز السعة.
- `google-apps-script/commercial/`: جسر الإصدار الآخر، غير مستخدم في نسخة الإدارة المحلية.
