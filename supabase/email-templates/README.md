# قالب دعوة فريق العيادة

- `invite-user.html`: قالب عربي RTL مُحسّن بطابع دعوة شخصية فاخرة، مبني بجداول وأنماط مضمنة لزيادة التوافق مع عملاء البريد، مع رابط Supabase الأصلي `{{ .ConfirmationURL }}` للزر والرابط الاحتياطي.
- `invite-user-subject.txt`: عنوان الرسالة.
- الملفات محلية داخل المشروع. تحققت في 2026-11-10 من لوحة المشروع التجريبي `ccuharkcusmsjdxfuamq`: صفحة Emails تعرض أن الرسائل تستخدم القوالب الافتراضية وأن إعداد SMTP مخصص مطلوب لتحريرها. لذلك الدعوات الحالية لا تستخدم هذا التصميم بعد.
- بعد إعداد SMTP، انسخي العنوان ومحتوى HTML إلى Authentication → Emails → Invite user، ثم احفظي واختبري الدعوة على بريد تجريبي. احتفظي بمتغير `{{ .ConfirmationURL }}` كما هو كي يعمل قبول الدعوة.
- لا تستخدمي مفتاح خدمة Supabase أو كلمة مرور بريد في ملفات المشروع أو القالب.

Supabase يقيّد البريد الافتراضي للعناوين المصرّح بها ويحد الإرسال، وهو مخصص للتجارب؛ إعداد SMTP مخصص مطلوب لتعديل القالب وإرسال رسائل الإنتاج. لم تُضف بيانات SMTP أو تُغيّر إعدادات الإرسال في هذا التحديث. راجعي [متطلبات SMTP الرسمية](https://supabase.com/docs/guides/auth/auth-smtp) و[دليل قوالب البريد](https://supabase.com/docs/guides/auth/auth-email-templates).
